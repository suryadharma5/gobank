# GoBank

A simple banking API built with Go for learning purposes.

## Tech Stack

- Go
- PostgreSQL
- Mux

## Setup

1. **Clone the repo**
```bash
git clone https://github.com/suryadharma5/gobank.git
cd gobank
```

2. **Install dependencies**
```bash
go mod download
```

3. **Setup PostgreSQL**
```bash
createdb gobank
```

4. **Run the app**
```bash
go run .
```
